# 个人晚年生活自主与互助指南

**为未来建立更多选择，让独立生活与彼此支持成为可能。**

## 项目简介

随着人口结构、家庭形态和生活方式的变化，越来越多人开始思考：

- 如果没有配偶或子女长期照料，如何安排自己的晚年生活？
- 如何在保持个人独立的同时，建立可信赖的社会支持网络？
- 如何应对疾病、意外、经济压力和日常生活能力下降？
- 如何让人与人之间的互助既有温度，又有规则和边界？
- 如何提前安排医疗意愿、财产事务和身后事务？

本项目希望围绕这些现实问题，整理一套可参考、可实践、可持续完善的个人生活自主与互助指南。它不以某一种家庭结构为前提，也不要求参与者必须单身、独居或选择某种养老方式。

## 核心理念

1. **自主生活：** 尽可能保持经济、身体、居住和个人决策上的独立。
2. **多元支持：** 不把晚年保障完全寄托在某一个人、家庭或组织身上。
3. **平等互助：** 鼓励彼此帮助，尊重个人意愿，劳动应有合理回报。
4. **信任有据：** 通过实际行为、透明规则和必要记录建立信任。
5. **风险防范：** 重视隐私、财产安全、专业服务和法律边界。
6. **持续实践：** 从小事情开始验证，不急于建立大型组织。

## 主要内容

- 健康管理与身体功能维护
- 经济安全与未来照护预算
- 居住安全与独立生活能力
- 单身人士及其他群体的生活互助
- 可信关系、服务规则与监督机制
- 心理健康、情感连接和生活意义
- 法律安排、医疗意愿与身后事务
- 个人生活档案和数字信息管理

## 如何参与

欢迎不同年龄、不同家庭结构、不同生活经历的人参与讨论。你可以：

- 分享真实的生活经验和互助案例。
- 提出对现有规划的修改建议。
- 补充经过核实的社区服务、专业服务和政策资源。
- 讨论互助过程中遇到的实际问题及解决方法。
- 帮助完善适用于不同人群的行动指南。

参与时请勿公开自己或他人的身份证号码、住址、病历、账户、联系方式等敏感个人信息。提交内容前，请先阅读 [贡献指南](CONTRIBUTING.md)。

## 项目边界

本项目是公共知识交流与个人行动规划项目，不是养老机构、保险产品、医疗机构、投资项目或资金互助平台。项目内容不能替代医疗、法律、财务及其他专业意见。实际执行时，应根据所在地法律法规和个人情况核实。

本项目不承诺任何成员提供终身照护，也不承诺任何互助关系能够替代专业服务。

## 项目愿景

希望让更多人在身体健康、经济独立和意识清醒时，就开始认真思考未来的生活。我们不必等到年老、疾病或意外发生之后，才第一次讨论如何互相帮助。

**提前准备，保持自主；平等互助，彼此尊重。**
